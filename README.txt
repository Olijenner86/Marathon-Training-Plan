Edinburgh Marathon 2027 iPhone Home Screen App

This is a Progressive Web App (PWA). For the iPhone "Add to Home Screen"
feature to work reliably, the folder needs to be hosted at an HTTPS web
address. Open that address in Safari, tap Share, then Add to Home Screen.

The app stores tick-offs and notes locally on the device.

Garmin integration is prepared in the interface but requires a hosted
backend plus Garmin's developer/API authorisation before live automatic
activity import can be enabled.
